# 公式编号引用

索引带编号的展示公式：

```md
$$
E=mc^2 \tag{3-1}
$$
```

## 两种并存的引用方式

普通写作沿用原有格式，无需迁移：

```md
由 $\text{(3-1)}$ 可知……
```

插件只把严格的 `$\text{(数字-数字)}$` 识别为蓝链，普通变量和其他行内公式不会被接管。

需要显式链接、任意描述或嵌入时使用：

```md
[[#=(3-1)|(3-1)]]
[[#=(3-1)|由归一化条件可知]]
![[#=(3-1)]]
[[另一篇笔记#=(3-1)|参见能量关系]]
```

- `[[#=`：输入时搜索公式并插入链接
- `![[#=`：输入时搜索并嵌入原公式
- 显式链接的别名可以写成任意说明文字
- 点击跳到公式原文，悬停可预览
- 修改 `\tag` 编号后，Vault 内的 `#=` 链接与嵌入会自动同步
- 自动生成的编号显示文字会更新，手写的自定义别名保持不变
- 跨文件嵌入默认隐藏原公式的 `\tag`，可在设置中重新显示
- PDF 导出时链接按普通正文打印，嵌入只显示公式本身

命令面板还提供正文编号、显式链接和公式嵌入三种插入命令。

普通的 `$\text{(3-1)}$` 没有记录目标文件，不参加全 Vault 自动同步；
可继续由原有 Templater 脚本在当前笔记内更新。

## 安装与构建

GitHub Release 提供 Obsidian 可直接安装的 `main.js`、`manifest.json`
与 `styles.css`。源码构建：

```bash
npm ci
npm test
npm run build
```

构建结果位于 `dist/main.js`。
